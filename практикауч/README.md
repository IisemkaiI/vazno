# Учет библиотечного фонда

## Запуск

1. Установите Python 3.10 или новее и MySQL Server 8.0.
2. В MySQL Workbench откройте `library_db.sql` и выполните весь скрипт кнопкой с молнией.
3. В этой папке откройте PowerShell и установите зависимости:

   ```powershell
   py -m pip install -r requirements.txt
   ```

4. По умолчанию приложение подключается к `localhost:3306` пользователем `root`, пароль `1234`, база `library_db`.
5. Запустите приложение:

   ```powershell
   py library_app.py
   ```

Если настройки MySQL отличаются, задайте переменные окружения `MYSQL_HOST`, `MYSQL_PORT`, `MYSQL_USER`, `MYSQL_PASSWORD` и `MYSQL_DATABASE` перед запуском.

## Возможности

- книги: добавление, просмотр, редактирование, удаление и поиск по названию, автору или жанру;
- читатели: добавление, просмотр, редактирование, удаление и поиск;
- выдача книг на 14 дней, возврат и фильтры по статусу;
- отчет по выдачам и книгам на руках в разрезе жанров;
- Coffee-палитра; режим оформления автоматически следует настройке Windows.

## Проверка

Тесты бизнес-логики выполняются без подключения к серверу MySQL и не меняют пользовательскую базу:

```powershell
py -m unittest -v test_library_core.py
```
